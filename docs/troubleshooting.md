# Диагностика

Команды сервера выполняются из корня репозитория. Начните с:

```bash
make ps
docker compose logs --tail=200 bot
```

Логи содержат причину ошибки, тогда как Telegram показывает короткое сообщение.

## Бот и окружение

| Симптом | Проверка и действие |
| --- | --- |
| `TELEGRAM_BOT_TOKEN is required` | Заполнить токен в `.env`, выполнить `make recreate-bot` |
| Ошибка `TELEGRAM_ALLOWED_USER_IDS` | Нужен хотя бы один числовой user ID через запятую, затем `make recreate-bot` |
| «Доступ к этому боту закрыт» | Проверить ID отправителя в allowlist; `@username` не подходит |
| Изменения `.env` не применились | Использовать `make recreate-bot`; `restart` сохраняет старое окружение |
| Polling conflict / другой процесс получает обновления | Остановить второй экземпляр с тем же токеном, включая локальный запуск |
| Рендер прошёл, но бот не возвращает файлы | Проверить ошибки отправки в логах: сеть и ограничения Telegram могут отличаться от локального upload-лимита |

`make up-direct` использует текущее значение `TELEGRAM_PROXY_URL`, а не очищает
его автоматически. Для прямого режима оставьте его пустым.

## Прокси

```bash
make logs-proxy
make proxy-check-xray
```

Для sing-box используйте `make proxy-check`. Успешная проверка синтаксиса не
доказывает доступность сервера, TLS или Telegram. Проверьте, что запущен нужный
движок, VLESS endpoint доступен с VPS, а SNI соответствует сертификату.

Для XHTTP + TLS нужен Xray. После остановки запускайте его `make up-xray`;
`make up-proxy` выбирает sing-box. После смены Xray-ссылки повторите генерацию,
проверку и `make up-xray`. [Все команды прокси](proxy.md).

## Права доступа

Если контейнер не может записать в `/data`, проверьте владельца checkout.
Для рекомендуемого пути:

```bash
sudo chown -R "$USER":"$(id -gn)" /opt/apps/historical-bloodlines-builder
make init
make recreate-bot
```

`make init` обновляет UID/GID, сохраняя настройки Telegram. Xray тоже читает
свой приватный конфиг с UID/GID checkout; после смены владельца пересоздайте
его командой `make up-xray`.

## YAML и оформление

| Симптом | Причина / действие |
| --- | --- |
| Бот не реагирует на изменение `config/*.yaml` | Копировать пресет в `data/render.yaml` |
| Изменение корневого `render.yaml` не влияет на Docker | На хосте контейнеру доступен `data/render.yaml`; проверить `BLOODLINES_RENDER_CONFIG` |
| `Render config ...` / unknown keys / duplicate key | Исправить YAML по [справочнику](render-configuration.md); ошибки не скрываются fallback-конфигом |
| Launcher использует прежнее оформление | Перезапустить launcher |
| Размер текста вырос в YAML, но почти не изменился в PDF | Увеличился и исходный холст; проверить конечный PDF, сравнить A4/A5 |
| Результаты на разных компьютерах отличаются | Сверить YAML, версию кода, Graphviz, Cairo/Pango и наличие Roboto |

В CLI начало вывода показывает путь выбранного конфига, размер текста и
межстрочный интервал. У бота фактические настройки есть в `render-settings.yaml`
из ZIP успешного задания.

## Excel и маршруты линий

- `misses headers`: заголовки должны стоять в первой строке или сразу после
  строки `Название`. Удалите посторонние служебные листы без нужной шапки.
- Повторяющийся `№`: назначьте уникальные положительные номера внутри листа.
  Учитывайте автоматические номера физических строк для пустых ячеек `№`.
- Предупреждение о placeholder: ссылка не разрешилась в полноценную строку.
  Проверьте написание/уточнение имени или добавьте человека в таблицу.
- Цикл или противоречивое поколение: проверьте направление родства и подсказки.
- Конфликт геометрии: проверьте конкретный лист, ручные поколения и порядок.
  Программа останавливается, если не может провести однозначные линии без
  запрещённых пересечений. Новый размер шрифта не гарантирует разрешимость.

Для подробной ошибки книги из бота скопируйте её в `data/input/` и запустите
`make render-pdf INPUT_FILE=book.xlsx OUTPUT_NAME=debug` и
`make render-eps INPUT_FILE=book.xlsx OUTPUT_NAME=debug`.

## Проверка рендера без Telegram

```bash
make smoke
```

Локально проверьте `dot -V`, `neato -V`, импорт CairoSVG и реальную сборку
[примеров CLI](local-run.md). Наличие Python-пакета `graphviz` или успешный
`dot -V` не проверяют Cairo/Pango, шрифты и EPS-конвертацию.

Если smoke успешен, а бот с конкретной книгой падает, смотрите ошибку задания
и проверяйте книгу с тем же конфигом. Подготовьте версию кода (`git rev-parse HEAD`),
настройки рендера, название листа и сообщение ошибки. Не публикуйте токен бота
и реквизиты VLESS вместе с диагностикой.
