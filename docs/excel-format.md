# Формат Excel

Поддерживается `.xlsx`. Каждый заполненный лист — самостоятельная родословная;
ссылки на людей разрешаются внутри неё. Начните с
[examples/input.example.xlsx](../examples/input.example.xlsx).

## Структура листа

Первая строка может задавать полное название: в `A1` — `Название`, в `B1` —
например, `Династия Комнинов (1081–1185)`. Тогда заголовки идут во второй строке.
Без служебной строки заголовки должны быть в первой, а названием схемы станет
имя вкладки. Не ставьте перед заголовками пустые строки.

| Колонка | Нужна в шапке | Содержимое |
| --- | --- | --- |
| `№` | Да | Положительный целый номер человека, уникальный внутри листа |
| `Имя` | Да | Отображаемое имя; строки без имени пропускаются |
| `Титул` | Да | Титул или несколько титулов; значение может быть пустым |
| `Начало правления` | Да | Начальный год или согласованный список годов |
| `Конец правления` | Да | Конечный год или список; допускаются открытые периоды |
| `Дети` | Да | Имена детей через `;` или перенос строки |
| `Брак` | Да | Имена супругов через `;` или перенос строки |
| `Поколение` | Нет | Положительное целое число, начиная с `1` |
| `Порядок в поколении` | Нет | Положительное целое число для порядка слева направо |
| `Примечание` | Нет | Сноска под схемой со знаком `*` у человека |

Обязательна сама колонка, а не заполнение всех её ячеек. В `Имя` нужны данные
для каждой учитываемой строки. Не переименовывайте обязательные заголовки.

Если `№` пуст, используется физический номер строки Excel. Это может
пересечься с явно заданным номером другой строки, поэтому лучше заполнить
уникальные номера всем людям. ID вычисляется из технического имени листа и
номера: изменение отображаемого `Название` не меняет идентичность, а
переименование вкладки или изменение `№` меняет её.

Листы с корректной шапкой без людей пропускаются. Служебный лист с произвольной
шапкой может вызвать ошибку отсутствующих колонок; удалите его из входной книги.
Формулы не пересчитываются программой: reader читает сохранённые Excel значения.

## Люди и связи

Один человек — одна строка. Ссылки `Дети`/`Брак` содержат имена, а не номера
строк. Можно ссылаться на человека ниже текущей строки: сначала создаются люди,
затем разрешаются отношения.

Несколько ссылок разделяйте точкой с запятой или переносом строки:

```text
1) Генрих V; 2) Жоффруа Плантагенет
```

Одноимённых людей можно уточнить титулом в скобках или после запятой:

```text
Альберт II (герцог)
Альберт II, герцог Австрии
```

Resolver учитывает нормализованное имя, уточнение, титулы и семейный контекст.
Номер из `1)` — маркер порядка ссылки, а не ID человека.
Если для ссылки нет отдельной строки, возможен placeholder — терминальная
подпись с предупреждением. Для человека с собственными датами, браками и детьми
создайте полноценную строку.

Для нескольких браков указывайте супругов и детей достаточно однозначно,
чтобы можно было определить конкретный союз. Программа рисует одного человека
один раз, а не копию для каждого брака. Супружеский знак — `=`; линия детей
выходит из соответствующего союза.

## Титулы и периоды правления

Титулы также разделяются `;` или переносами строк и нормализуются со строчной
буквы. Запятую после имени добавляет formatter только перед текстовым титулом;
вписывать её вручную в `Имя` не нужно.

| Имя | Титул | Отображение |
| --- | --- | --- |
| `Оттон I` | `король Восточных Франков (936-973)` | `Оттон I, король Восточных Франков (936-973)` |
| `Рюрик` | `862-879` | `Рюрик 862-879` |

Для нескольких периодов позиции в списках начала и конца должны соответствовать:

```text
Титул:             Король; Император
Начало правления:  936; 962
Конец правления:   973;
```

Конечная пустая позиция сохраняет открытый период. Даты отображаются как
`(936-973, император с 962)`. Полные периоды выводятся раньше уточнений
`с ГОДА`, даже если титулы в Excel идут в другом порядке.

## Примечания

Впишите текст в необязательную колонку `Примечание`. Он попадёт в сноску под
схемой; у имени появится `*`. Если в начале примечания нет `*`, formatter
добавит его. Размер сносок регулируется `typography.note_font_size_pt`,
а не размером основного текста.

## Сложная раскладка

Без `Поколение` и `Порядок в поколении` раскладка вычисляется автоматически.
Подсказки меняют геометрию, а не родство.

- `Поколение` фиксирует глубину ветви. У супругов числа могут различаться:
  общий супружеский блок размещается на самом глубоком явно заданном уровне.
- `Порядок в поколении` задаёт относительный порядок блоков слева направо.
  Используйте шаг `10`, `20`, `30`, чтобы оставлять место для вставок.
  Это не координата и не расстояние в пунктах.

Частично заданный порядок ограничивает пронумерованные блоки. Остальные могут
перемещаться между ними с учётом топологии родства и маршрутов линий. Для полного
контроля задайте порядок всем блокам нужного ряда. В браке между поколениями
учитывается порядок человека из самого глубокого явно заданного поколения.

Сборка отклонит повторяющиеся номера, циклы родительства, противоречивые
поколения/порядок и неразрешимые конфликты маршрутов. При такой ошибке сначала
проверьте родство и ручные подсказки; перестановка строк Excel не заменяет
явное управление порядком.
